**Критерий конкурентного теста:** не «похоже ли на нашу идею», а «почему человек должен отказаться от одной из этих альтернатив в реальной ситуации?»

**Search intent:** 3–7 конкретных гипотетических запросов на основной площадке + actual date/geo/surface/competitors; факт запросов подтверждается **реальным пользовательским поиском**, а не произвольными словами автора.

| Query (language) | Чего ищет человек | Где и когда проверено | Контент реально соответствует? | Есть ли независимый спрос или UNKNOWN? |
| --- | --- | --- | --- | --- |
| | | | | |

**Прокси и ограничения:** Wordstat = Yandex web, Trends = normalized Google web; Play search terms = свой published listing; RuStore sources = свой store. Не подменять ими downloads/installs конкурентов.

| Участник, без идентификаторов | Знаком с механикой? | Недавняя реальная ситуация и выбор | Реальное substitute | Что ценит и чем недоволен | Какое поведение наблюдали? |
| --- | --- | --- | --- | --- | --- |
| A | | | | | |
| B | | | | | |
| C | | | | | |

**Не спрашивать:** «Скачал бы эту игру?», «Нравится идея?», «Играл бы каждый день?» как основу go/no-go. Допустимы как вторичные субъективные комментарии, но не переводить их в прогноз установок.

**Пример начала ненаводящего интервью:** «Расскажи, во что ты последний раз играл на телефоне и почему открыл именно это, а не другое». Затем попросить вспомнить конкретную причину выбора/удаления. Если наблюдение записи происходит — документировать разрешение и условия.

## 6. Шесть обязательных gates — без псевдо-весов

| Gate | PASS / UNPROVEN / BLOCKED / REJECT | Факт, дата/источник, alternative | Дешевейший следующий тест и лимит усилий |
| --- | --- | --- | --- |
| G1 real need / genuine substitute | | | |
| G2 target audience reachable | | | |
| G3 reason to switch | | | |
| G4 actual core payoff observed | | | |
| G5 production + content maintenance bounded | | | |
| G6 legal/platform/monetization feasible | | | |

**Hard stop:** один доказанный непреодолимый blocker достаточен для HOLD/REJECT. «UNPROVEN» не превращать ни в успех, ни в провал. Формальное завершение игры без финансовой возможности — не коммерческий fit.
