# Независимая проверка коммерческих разборов Ayo

**Дата:** 13 ноября 2026. **Объект:** [Commercial Teardowns](COMMERCIAL_TEARDOWNS_2026-11-13.md). **Результат:** материал пригоден для выбора ограниченных экспериментов; ни один коммерческий эффект в нашем портфеле не объявлен измеренным.

Проверку разделили на поиск первичных материалов, независимое чтение кадров, платформенные контракты и офлайн-воспроизведение Block Blast. Прямые первичные URL приведены в основном документе и [машинном реестре](../../research-artifacts/commercial-teardowns-2026-11-13/source_manifest.json). Вторичные транскрипции используются с явной маркировкой.

## 2. Что независимо воспроизведено в Block Blast

Свежее скачивание и выполнение 13 ноября. Исходники harness и загружаемые ими JavaScript просмотрены до исполнения. APK, аккаунты, рекламные SDK и запущенная игра не использовались.

| Проверка | Результат |
| --- | --- |
| SHA-256 двух публичных ZIP | Совпадают с опубликованными и предыдущим проходом |
| Внутренний Android manifest | 63/63 файлов совпали |
| Внутренний iOS live manifest | 10 содержательных файлов совпали; самоссылочная запись SHA256SUMS устарела |
| Авторский rule harness | 28/28 проверок; условный запрос алгоритма 9 |
| Авторский generator harness | На заданной доске выбрал [2,3,13] при ограничениях стенда |
| Авторские placement-проверки | Ноль полных решений для обеих предоставленных позиций |
| Новый независимый coordinate-set solver | Ноль решений; все порядки и позиции, одновременная очистка строк и столбцов |
| Положительные контроли | Обе тройки размещаются на пустом поле; пересекающиеся строка и столбец удаляются одновременно |

Результаты, хеши, команды и ограничения сохранены в [JSON](../../research-artifacts/commercial-teardowns-2026-11-13/blockblast_reproduction_results.json). [Собственный решатель](../../research-artifacts/commercial-teardowns-2026-11-13/blockblast_independent_solver.py) не включает код игры. Входные данные берутся из отдельно скачанных публичных архивов.

Полный поиск использует 8×8, перемещения без вращения и дополнительных способностей. Android-доска синтетическая, iOS — предоставленный автором capture. 171 у автора означает попытки размещения с повторением префиксов для отдельных порядков, а не уникальные состояния. Общий независимый DFS посетил 156 и 16 узлов соответственно.

### Границы доказанного

- Установлены поведение опубликованного модуля при заданных входах и свойства двух досок. Независимая расшифровка из подписанного APK/IPA не выполнена.
- Generator harness ограничивает список кандидатов, использует тождественное перемешивание, отключённый timeout и отсутствие downgrade. Это не полный production pipeline.
- Сохранённое предыдущее eCPM допускает fallback/backfill; оно не всегда равно цене непосредственно предыдущего оплаченного показа.
- Последние успешные rewarded — флаги приложения; в материалах описан synthetic-success путь. Реальное внимание человека к рекламе не проверяется этим тестом.
- Параметр 420 секунд не участвует в проверенном решении. Он не является подтверждённым cooldown данной ветки.
- Другие правила могут препятствовать запросу или менять результат. Подходящие входы не гарантируют финальную неизменённую невозможную выдачу.
- Предоставленный iOS live эпизод относится к PersonalMarginBreakTrait. Сохранённый рекорд был изменён для теста; это не live-срабатывание рекламного harvest-условия.
- Не установлены доля затронутых игроков, частота применения, актуальное развёртывание и прирост выручки.

## 3. Проверка экономической интерпретации

**Близость к победе.** Процент выполненных целей не определяет число нужных действий. В рекомендации требуется проверять реальное состояние и полезность помощи. Изменение генератора одновременно с оффером исключено из первого предложенного теста, поскольку оно мешает понять причину результата.

**Знаменатель.** Основная метрика включает всех первоначально назначенных пользователей и полное окно наблюдения. Добровольно выбравшие рекламу, выжившие активные и завершившие уровень — результаты воздействия, а не готовые контрольные группы. [Определение когортного ARPU в AppMetrica](https://appmetrica.yandex.ru/docs/ru/mobile-reports/cohort-report) поддерживает такой денежный знаменатель.

**Источники денег.** Один показ не складывается повторно из кабинета сети и AppMetrica. Загрузка, onImpression, callback награды, сохранённая помощь и выплата издателю обозначают разные факты. Неизвестный доход не заменяется нулём.

**Прибыль компаний.** King 2022 — сегментный показатель, исключающий часть расходов, а не чистая прибыль отдельной игры. Duolingo 2025 — преимущественно подписочный бизнес. Прибыльность компаний не атрибутирована обнаруженным флагам. Данные SYBO с кадра не объявлены независимо проверенной отчётностью.

**Эксперимент Duolingo.** Paper описывает причинный production-тест, который мы не воспроизводили. +2,0% — относительное изменение recurring D7 у новых пользователей; не +2 процентных пункта, не обычный install D7 и не рост прибыли. Проверены текст определения и таблица 8.

**Практическая ценность.** Отсутствие доказанного uplift у конкурента не блокирует исследование и подготовку маленького собственного теста. Результат работы должен быть конкретным: выбранный существующий путь, изменение одного фактора, стоимость, исходная когорта и критерий выбора. Построение универсального директора или бессрочное накопление данных этим не обосновано.

## 4. Остаточные неизвестные

Независимое чтение итогового draft выявило ещё три точечных дефекта формулировок. Все исправлены в основном документе и карточке: явно требуется случайное, а не только устойчивое назначение; денежный источник должен связываться с тем же пользователем/вариантом; неизвестные и недействительные суммы отделены от нуля с проверкой полноты по группам. Это особенно существенно для Yandex Games web, где callback не содержит индивидуального дохода. Без этой связи денежный uplift не вычисляется; техническая проверка воронки остаётся полезной.

Dicero и Duolingo видео не просмотрены; наличие их адресов не заменяет просмотр. Для Candy, Royal Kingdom, Subway и Tinder не получены полные воспроизводимые source bundles. Не проверены подписанные оригинальные сборки этих приложений, текущие серверные назначения, закрытые рекламные кабинеты и финансовые данные владельца портфеля.

Работа не меняет действующие продуктовые решения и не выдаёт исследовательские гипотезы за принятую монетизационную политику. **Рекомендуемый следующий результат:** технически и экономически описанный существующий rewarded-путь, затем один ограниченный эксперимент из карточки.
