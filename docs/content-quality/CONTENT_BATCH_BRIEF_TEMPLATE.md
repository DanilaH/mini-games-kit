## 4. Только endless/procedural выдача

**Frozen controls:** weighted proven random / старый локальный dealer / текущий live policy. Какой candidate отличается по одному ключевому фактору?

| Показатель на одном board/tray | Baseline | Candidate | Предел/причина изменения |
| --- | --- | --- | --- |
| Полный witness FOUND | | | |
| Независимые разумные first+second branches | | | |
| Доступные обычные lines и мультиочистки | | | |
| Разные правдоподобные пути к all-clear | | | |
| Survival risk / ошибки after 1/2 moves | | | |
| Nontrivial decisions (не все ходы безразличны) | | | |
| Decision signature / недавние повторы | | | |
| Бюджет вычислений, UNKNOWN, fallback | | | |

**Длинная траектория:** как меняются интервал обычных линий, занятость/свободные области, продолжительность до реального поражения, all-clear (не единственная награда), censored runs и state/rng hashes по **разным независимым стратегиям**?

**Не выводить эмоцию/retention из статистики бота.** Указать, какие действия игрока доступны и какие именно синтетические политики их выбирали. Исходное состояние для snapshot comparison одинаковое; full-rollout diverges и должен интерпретироваться отдельно.

## 6. Реальный редакторский и human test

| Эпизод / reviewer | Что *сам* сделал игрок | Где объяснение и где ошибка | Новое или знакомое mental move | Было ли интересно/справедливо? | Неизвестное |
| --- | --- | --- | --- | --- | --- |
| | | | | | |

**Ненаводящие вопросы после эпизода:** «Что здесь пришлось понять?», «Почему именно этот ход?», «Чем это отличалось от предыдущей задачи?», «Что показалось скучным/интересным?», «Что произошло бы при другом выборе?»

Если респондент не проходил игру — статус **не проверено на людях**, не придумывать оценку.
